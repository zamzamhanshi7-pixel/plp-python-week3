
# Grade Reporter & Bug Hunt

## Assignment Files

- grade_reporter.py: Calculates learner grades, pass count, fail count and average score.
- bug_hunt.py: Fixes three bugs in a while loop program.

## Reflection

The hardest bug to find was the loop condition because the program could run without showing an error but still give the wrong answer. I knew something was wrong because the expected sum was 15, but the program produced a different result.
